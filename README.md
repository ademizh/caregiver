# Caregiver Database Web Application

A Django web application for managing a caregiver-service database with CRUD operations and SQL query execution.

## Overview

This project was developed as a database systems assignment. The application manages data related to users, caregivers, members, addresses, jobs, job applications, and appointments. It demonstrates relational database design, SQL querying, backend development, and deployment of a simple database-driven web application.

## Features

- Relational database schema design
- MySQL database integration
- CRUD operations for managing database records
- SQL query execution using SQLAlchemy
- Data validation through constraints such as NOT NULL, UNIQUE, and FOREIGN KEY
- Web interface built with Django
- Deployment on PythonAnywhere

## Tech Stack

- Python
- Django
- MySQL
- SQLAlchemy
- HTML / CSS
- PythonAnywhere

## Database Tables

The database includes the following main tables:

- USER
- CAREGIVER
- MEMBER
- ADDRESS
- JOB
- JOB_APPLICATION
- APPOINTMENT

## Project Workflow

1. Designed and created a relational database schema.
2. Inserted test data into each table while satisfying database constraints.
3. Implemented SQL queries and update operations using SQLAlchemy.
4. Built a Django web application with CRUD functionality.
5. Deployed the application on PythonAnywhere.
